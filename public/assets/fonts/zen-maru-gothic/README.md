# Zen Maru Gothic 字体资源

保留本站原有的 **Zen Maru Gothic** 字体家族，提供 400（Regular）、500（Medium）、700（Bold）三个实际字重的站内文件。全局回退顺序没有修改。

来源：[Google Fonts 的官方字体目录](https://github.com/google/fonts/tree/main/ofl/zenmarugothic)。下载日期：2026-10-25。

- 原文件：`ZenMaruGothic-Regular.ttf`、`ZenMaruGothic-Medium.ttf`、`ZenMaruGothic-Bold.ttf`。
- 使用 FontTools 将 TTF 无子集转换为 WOFF2；保留字体名称、字重和字符映射。
- `source-manifest.json` 记录源文件 SHA-256、字重、字符映射数量和输出大小。
- `fonts.css` 声明对应字重，使用 `font-display: swap`。
- 官方许可完整保留在 [OFL.txt](OFL.txt)。

此字体的字符覆盖范围与原版一致。未包含的简体字仍沿用本站原来的回退链；格式转换不补造字形，也不将字体替换为其他家族。
